# AGENTS.md

## Project Overview

This repository contains a SwiftUI-based iOS app (`ResyPro.xcodeproj`) along with local Swift packages located under `ResyPro/Packages`.

- **License**: MIT  
- **Platform**: iOS  
- **Architecture**: Modularized via Swift packages  
- **UI Framework**: SwiftUI  

## Development Requirements

- Xcode 15+
- Swift 6 toolchain

### Opening the Project

As of now there is not support to open or test the project. So do not try, unless explicitly asked to test a package that supports it.

## Coding Guidelines

- Follow standard Swift style conventions. Please lint the code before comitting
- Avoid committing `.DS_Store` or any autogenerated build files.
- Document **all public types** in Swift packages.
- Favor writing code in packages over the main app target.
- Indentation style should be tabs.
- For inits with multiple paramets, put them on separate lines.

## Pull Request Tips

- Provide a concise summary of your changes and how you validated them.
- Ensure everything builds successfully using the CLI command above.
- Keep commit history clean — squash before merging when possible.
